## 开关及原版操作

1. 开关默认关闭。验证原版新建、单段升级、反向操作及 Shift 单段操作。
2. 类型工具只在升级模式显示开关；电气化、公交、电车、锁定和边缘设施工具显示开关。
3. 开启后点击一段路，等待预览。确认前路网和余额不发生变化。
4. 改变目标、参数或建造工具，旧预览失效，不能确认旧方案。关闭建造菜单后再次打开，开关已关闭。
5. 检查中文／英文显示、窗口关闭按钮、原因滚动区、长错误信息换行及 UI 缩放。

## 连通范围

1. 点击环路任意一段，应包含环路和所有支线，各段只统计一次。
2. 桥梁、隧道两端继续遍历；断开的另一片网络保持原样。
3. 平交道口只遍历当前工具的公路或铁路；立交和相邻未接通路段不算相连。
4. 车站／车库的锁定内部路段列为跳过项；有实际节点连接的后方路段仍会被找到。没有物理连接的另一个站台不会因属于同一车站而自动纳入。
5. 已符合目标和受阻路段均不终止遍历。

## 升级工具

| 场景 | 预期 |
| --- | --- |
| 铁路模板替换 | 使用当前所选轨道，未涉及的设施保留 |
| 混合轨道整网电气化 | 各自切到自己的电气化变体，不统一为普通轨道；自定义车道速度与偏移保留 |

| 公交专用道 | 单向／双向正确，非目标车道和电车设施保留 |

| 道路锁定／解锁 | 锁定状态和归属符合原版玩家操作规则，重复操作不收费 |
| 隔音墙等设施 | 所选设施及侧别正确，其他设施保留；不兼容桥隧列为跳过 |
| 已有信号、站点和路径点 | 数量、名称、位置、归属及线路使用保留 |

## 顺序提交、异常和取消

1. 制造一段碰撞或超出目标坡度要求的路段。该段跳过，其余可升级路段继续处理，窗口显示实际引擎原因。
2. 若引擎替换需改动其他路段／节点／建筑／设施，应跳过并显示对应原因。
3. 确认前更改其中一路段，整次预览失效；重新扫描后才能提交。
4. 执行中更改未来待处理路段，应跳过过期路段，不重新收费或处理已经完成的路段。
5. 执行期间点击取消。当前已提交命令返回后停止后续命令，成功升级保留，统计正确。
6. 执行期间切换工具或关闭建造菜单，停止后续任务；窗口能显示最后命令的结果。
7. 余额不足时停止剩余任务。核对实际账户变动、窗口累计费用与原版同段报价。
8. 对大量路段执行，观察扫描与检查进度、界面响应、取消反馈，以及日志中每段只有一条提交结果。
9. 保存并重新加载，升级结果正常；停用 Mod 再读档，已完成的原版路网修改仍保留。
