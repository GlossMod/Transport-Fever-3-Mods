# 内置修改器

TF3 Mod `xiaom_global_tuning`，revision 7；依据本机 Steam Build `25533170`。本版本面向当前本地 staging_area，未对外发布。

## 使用

1. **完全退出并重新启动游戏**，让更新后的 UI 脚本与样式生效；以后修改选项无需保存或自动重载。
2. 点击右下角工具栏上方的圆形齿轮按钮，悬停提示“打开内置修改器，调整全局倍率”。入口沿用原版工具栏的圆形底图、阴影、蓝白配色与悬停/按下反馈。窗口分为生产与动力、载具与运输、时间控制三组，使用双列布局。
3. 选择档位后，约 0.35 秒自动保存配置并提交实时命令。不需要点“保存”。
4. 标注“下次载入”的资源项目在下次正常载入地图时应用；本 Mod 不会代替玩家保存或重载地图。
5. “重新应用”重试配置写入和实时命令；“恢复默认”记录默认选项并应用。恢复默认的时间项表示保持当前游戏速度，不会自动解除暂停。

窗口始终可编辑和关闭。关闭窗口后，后台继续处理已确认写入配置的修改。新的工厂和购入载具会在后台检查时收到实时倍率，通常在 3 秒内开始处理；大量实体会分批完成。

## 生效范围

| 设置 | 当前实现 |
|---|---|
| 工厂生产 | 实时，原料和运输需求仍然有效 |
| 货运容量、客运人数 | 下次载入 |
| 满载货物重量 | 下次载入，空车重量保持原值 |
| 货运、客运装载速度 | 下次载入 |
| 载具与路网速度 | 载具最高速度实时；道路、轨道、桥隧、道口限速下次载入 |
| 火车牵引能力 | 下次载入，仅铁路动力车辆及动车组动力单元 |
| 模拟速度、日历速度 | 实时，支持暂停模拟和暂停日期 |

容量、重量、装载、牵引及路网属于资源加载阶段的数据。当前版本没有实现这些项目的全实时更新，不能把“配置已保存”理解为所有资源已经热更新。窗口逐项标注生效方式，并显示尚待载入的数量。

实时载具速度使用原生最高速度修正，实际行驶仍受当前路网限速、动力、交通和停靠限制；如果需要路网同步提速，需正常重新载入。实时工厂产能和载具速度占用引擎的 `productivity`、`topSpeedScale` 全局控制值，会替代同字段的单独修正；载具噪音、污染和舒适度修正保留。未使用这两项实时控制时，默认 1 倍不覆盖已有实体修正；曾调整后恢复 1 倍会复位本 Mod 控制的字段。

前八项提供 0.1、0.25、0.5、0.75、1、1.5、2、3、5、10、20、50、100 倍。代码默认 1 倍；本机首次配置保留了用户截图中的客运人数 10 倍，其余为 1 倍。正容量取最近整数且至少为 1，零值和特殊哨兵保留。客货混合配置保留共享舱室关系。

模拟速度为保持当前设置、暂停、1、2、4、8、16、32、64、100 倍。日历速度为保持当前设置、暂停日期以及上述小数/整数档位。日期暂停不会阻止车辆移动。时间在载入后初始化一次，以后只有编辑对应时间项或点“重新应用”才再次发送命令；可正常使用原生速度按钮。实际模拟速度受引擎和机器性能影响。

## 独立配置

本机配置文件：

`C:\Program Files (x86)\Steam\userdata\233840157\3493540\local\mod_settings\xiaom_global_tuning\settings.lua`

配置是版本化 Lua 数据表，由原生 `app.loadUserdata/saveUserdata` 读取和保存。所有存档共用；新版本不使用 Mod 参数页，不写 `modParams` 或 GUI 存档数据，不发送保存、读取存档元数据或载入存档的调用。已有旧版本参数仅在首次缺少独立配置时尝试迁移。

**配置不存进存档，不等于所有游戏状态都不进存档。** 实时命令改变的是原生实体状态；玩家正常保存时，生产、最高速度修正及时间状态仍可能被引擎保存。再次载入启用本 Mod 的地图时，会按当前本机配置重新应用；当前没有实现“保存时剔除所有原生修改状态”。

资源加载线程没有 App 接口时，读取 `content/local_settings.res.lua` 的本地缓存。此缓存经本机 staging_area 联接更新，属于本地工作区数据，不是存档数据。主配置保存在 Mod 目录之外，更新脚本不会覆盖它。本版本不要直接搬到 `mods/release` 或对外打包：改变安装位置之前需要适配缓存写入位置。

配置写入后立即回读检查。失败时窗口给出错误，新的实时修改不会被后台悄悄应用，可点击“重新应用”重试。无效选项回退默认值，损坏配置不会在窗口初始化时被自动覆盖。

## 注意与验证

- 此 Mod 不改变城市增长，不清除已有货物、不删除或替换车辆，不主动生成存档副本。
- 兼容标准载具和资源元数据，建议放在相关数据 Mod 后面。步行通道与机场滑行道保留原值。
- 缩小容量后的已装货行为、实际物理表现及移除后的状态仍需用户在存档副本确认。
- 封面 `_metadata/0.png` 和中文名称保留；封面为 AI 功能示意图，不是实机截图。
- 日志前缀为 `[xiaom_global_tuning]`，记录配置读取、资源修改、实时命令错误及待载入项。

当前验证范围见 `VALIDATION.md`。遵照项目 AGENTS.md，本轮不运行游戏或回归测试用例，交由用户测试。
