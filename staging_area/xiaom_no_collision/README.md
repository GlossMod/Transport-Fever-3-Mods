# 无碰撞 / Anarchy

Transport Fever 3 本地 Mod，英文名称 Anarchy，中文名称无碰撞，修订 3。保留身份 xiaom_no_collision，一个 Mod 一个文件夹。

## 启用与使用

本机游戏 staging_area 已联接工作区。在模组设置中检索 Anarchy 并启用。更新后重启游戏，再重新载入地图。

1. 用标准道路、建筑或模块工具摆出预览。
2. 预览仅受非致命的“碰撞”或“曲率过大”限制时，Anarchy 窗口提供“强制建造当前预览”按钮。
3. 点击按钮提交地图上最后显示的预览。费用、玩家归属和退款由游戏原生命令处理。

普通合法位置仍使用原版建造操作。碰撞位置的原版预览可能保持红色，此时用 Anarchy 窗口的强制建造按钮提交。

鼠标移入按钮区域时保留最后的自有预览副本。切换工具、改选建筑或关闭窗口会丢弃预览；提交时禁止重复点击。致命错误和其他建造错误继续阻止操作。

## 实现范围

覆盖标准道路、道路节点、建筑和模块建造菜单。读取原版只读预览，在自有 Lua 错误副本中精确处理 Collision / Too Much Curvature 及当前语言翻译，用于判断强制建造按钮是否可用；原版预览数据、费用、声誉、其他错误、警告和信息保持原值。通过原生 makeWorldBuildProposalCmd 的 ignoreErrors=true 提交实际建造，先 clone 复制借用提案。

修订 3 修复建筑预览回调写入只读 `errorState` 的异常。菜单扩展与强制预览捕获异常会记录原因、使旧强制方案失效，并返回原版回调结果，避免 Mod 扩展阻断普通建造。

保留原生模型碰撞体、道路模板和建筑生成脚本。轨道菜单、资产画笔和第三方自定义搬移工具不在此钩子范围内。允许重叠不保证所有路口几何、车道连接或模块组合有效；原生致命检查无法由此跳过。移除 Mod 后，再次改建重叠建筑可能恢复原版限制。
